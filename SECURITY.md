# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/dsd-toolbox/ffmpeg-dsf/security/advisories/new),
not in a public issue. Include the version, the platform and a file or steps that reproduce
the problem. Fixes are released as soon as they are ready.

Part of the [DSD Toolbox](https://github.com/dsd-toolbox/dsd-toolbox).
